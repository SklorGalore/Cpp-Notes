\section{C++ Basics}

\subsection{Comments}

Single line comments are done with "//"
\begin{minted}[linenos, style=autumn]{cpp}
	std::cout << "Hello world!"; // Everything from here to the end of the line is ignored
\end{minted}
Multi-line comments are done with "/*...*/"
\begin{minted}[linenos, style=autumn]{cpp}
	/* This is a multi-line comment.
	* the matching asterisks to the left
	* can make this easier to read
	*/
\end{minted}

\subsection{Variable Declaration and Assignment}

Variables are declared using their type and identifier
\begin{minted}[linenos, style=autumn]{cpp}
	int main()
	{
		int x;    // define an integer variable named x (preferred)
		int y, z; // define two integer variables, named y and z
		
		return 0;
	}
\end{minted}
Variables do not need a value when they are declared, but \textit{can} be given one if it makes sense

\begin{minted}[linenos, style=autumn]{cpp}
	int a;         // default-initialization (no initializer)
	
	// Traditional initialization forms:
	int b = 5;     // copy-initialization (initial value after equals sign)
	int c ( 6 );   // direct-initialization (initial value in parenthesis)
	
	// Modern initialization forms (preferred):
	int d { 7 };   // direct-list-initialization (initial value in braces)
	int e {};      // value-initialization (empty braces)
\end{minted}

\section{Functions}

\subsection{Function Declaration}

Functions are declared with a return type and an identifier, along with the arguments they take

\begin{minted}[linenos, style=autumn]{cpp}
	returnType functionName() /* This is the function header 
	(tells the compiler about the existence of the function)*/
	{
		// This is the function body (tells the compiler what the function does)
	}
\end{minted}
Functions can call other functions, but a function can not be defined within another one.
Functions can either return a value, or not (void).
Main must always return an integer (int) which is known as a status code that can be used to indicate whether or not the code performed as it should have.

\subsection{Function Parameters}

Function parameters are defined when the function is declared
\begin{minted}[linenos, style=autumn]{cpp}
	// This function takes no parameters
	// It does not rely on the caller for anything
	void doPrint()
	{
		std::cout << "In doPrint()\n";
	}
	
	// This function takes one integer parameter named x
	// The caller will supply the value of x
	void printValue(int x)
	{
		std::cout << x << '\n';
	}
	
	// This function has two integer parameters, one named x, and one named y
	// The caller will supply the value of both x and y
	int add(int x, int y)
	{
		return x + y;
	}
\end{minted}
These pre-defined values are known as \textit{parameters}.
Values passed to a function are known as \textit{arguments}.
